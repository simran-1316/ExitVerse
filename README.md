# 🌍 ExitVerse

**Don't Just Plan the Escape. Prepare for What Could Go Wrong.**

ExitVerse is a simulation-based emergency planning platform that helps planners test evacuation plans against disruptions such as road closures, floods, and shelter capacity limitations.

## 🚨 Key Features

* 🗺️ Road network visualization using OpenStreetMap.
* 🚧 Simulate road closures and disaster scenarios.
* 🛣️ Find alternative evacuation routes.
* 🏠 Check shelter capacities and assignments.
* 📊 Compare plans based on travel time, affected groups, and feasibility.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Leaflet
* **Backend:** Python, FastAPI
* **Routing & Simulation:** NetworkX, Dijkstra/A*
* **Database:** PostgreSQL + PostGIS (planned)
* **Map Data:** OpenStreetMap

## ⚙️ Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd ExitVerse
   ```
2. Install frontend dependencies:

   ```bash
   npm install
   ```
3. Start the frontend:

   ```bash
   npm run dev
   ```

*Backend setup will be added as the API and database are integrated.*

## 📌 Project Status

Currently under development. The prototype uses simulated scenarios and sample data to demonstrate evacuation planning and route analysis.

## ⚠️ Disclaimer

ExitVerse is a decision-support prototype, not a replacement for official emergency instructions or verified emergency response systems.
